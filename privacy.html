Privacy policy

Effective October 22, 2026

agent-inbox is a plugin for Claude Code and an extension for pi. It runs on your computer.

Data that it collects

It collects no data. It has no server, no account and no telemetry. The author, Carlos Tosta, gets no data about you or about how you use the plugin.

Data that it keeps, and where

It keeps one JSON file for each project on your computer: ~/.agent-inbox/<project>-<hash>.json. If you set AGENT_INBOX_DIR, the file is in that folder.

The file contains the items that you or your coding agent write. Each item has a title, an optional detail, a kind and a blocking flag. It also has the name of the agent or person that added it, and the time when it opened. When an item closes, the file records the time, who closed it, and any note about why. The file also contains the path of the project.

Open items stay in the file until you close them. The plugin keeps the 50 most recent closed items, so that you can open them again. The plugin removes older closed items. To delete all the data, delete the file or the ~/.agent-inbox folder.

Data that it sends

The plugin does not use the network, and it does not start programs. In your session, it gives your coding agent two types of text:

  • When the open items change, it adds a short hidden note next to your next prompt. The note has the number, kind, title, first line of detail and source of each open item.
  • When you type /explain or click Explain, it sends one prompt that contains that item. The agent uses this prompt to explain what it needs from you.

Your model provider gets this text with the rest of your conversation. The privacy terms of that provider apply. agent-inbox sends no data to other places.

This website

This website counts page views with GoatCounter. GoatCounter sets no cookies and collects no personal data. For each view, it records the page, the referring site, the browser, the screen size and the country. It does not keep your IP address. This applies only to the website. The plugin collects no data.

Children

agent-inbox is a tool for developers. It is not for persons younger than 18.

Changes

If the plugin changes how it uses data, the author updates this page and its effective date. The gh-pages branch of the source repository keeps the history of this page.
