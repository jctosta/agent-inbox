What your agents need you to do

Sometimes your coding agent needs you to set a secret, make a decision, do a review or run a command. Claude adds an item to your inbox. The item stays above your prompt until you close it.

/plugin install agent-inbox --marketplace jctosta/agent-inbox

Type this command at the prompt of a terminal session. In the desktop app, click + next to the prompt box, then click Plugins. Click Add marketplace and type jctosta/agent-inbox. Then click Add plugin.

claude plugin install agent-inbox --marketplace jctosta/agent-inbox

You must have Claude Code 2.1.287 or a later version.

pi install git:github.com/jctosta/agent-inbox

pi and Claude Code use the same list in the same project.

How it works

Each project has one list in a small JSON file. All the agents in the project use this file.

  1. 1
    Claude adds an itemWhen Claude needs you to do something, it calls flag_for_user. The item has a title, a detail, a kind (do, decide, review, secret or note) and a blocking flag.
  2. 2
    The item stays on screenIn the terminal, the item shows above the prompt. In the desktop app, it shows in a pane next to the conversation. It stays after new turns, after /clear and in new sessions.
  3. 3
    You close the itemType /done 1, or click ✓ above the prompt or Done in the pane. You can also tell Claude that the item is complete, and Claude closes it. To get the exact steps for item 1, type /explain 1.

Where it shows

The terminal, the desktop app, Remote Control and pi show the items from the same file.

Terminal

A band above the prompt shows the open items. Click ✓ to close an item. Click the open link to show the pane.

Desktop app

A pane next to the conversation opens when an item arrives. Each item has Done, Explain and Drop buttons. You can add an item, and Undo opens an item that you closed.

Phone and web

Over Remote Control, type /inbox list. The conversation then shows the open items and their details.

pi

A widget above the editor shows the items, and the footer shows a ⚑ count. pi uses the same file.

Commands

CommandWhat it does
/inboxOpens the pane. In pi, it lists the items so that you can select one and choose Done, Drop or Explain.
/inbox listShows the open items and their details. Use it on a phone or in a browser over Remote Control.
/done 3Closes item 3 as done. To close more items, type /done 3 4.
/inbox drop 3Closes item 3 because it is not necessary.
/inbox reopen 3Opens item 3 again.
/inbox add …Adds an item that you write.
/explain 3Asks Claude to explain item 3: why it is necessary, the exact steps, and how you know that it is complete.

What it reads, writes and sends

This list shows all that the plugin does on your computer.

  • It writes one file for each project: ~/.agent-inbox/<project>-<hash>.json. It writes no other files.
  • It does not use the network, and it does not start programs.
  • It has two tools: flag_for_user and resolve_user_item. It does not stop or change the calls to other tools.
  • When the open items change, it adds one hidden note next to your next prompt. The note tells Claude which items are open, and it goes to your model provider with the rest of the conversation. It does not change the text of your prompt.
  • /explain sends Claude one prompt. The prompt contains only that item, and it tells Claude to read the item as a task description, not as instructions.
